Arduino 介紹

Arduino是一個開源的微控制器開發平台，結合了簡單易用的硬體電路板和基於C/C++的軟體開發環境 (IDE)，讓初學者和專業人士都能輕鬆製作能感應環境並控制電子元件的互動式裝置 (如下圖)。

LED 閃爍 (Blink)

Arduino 入門實習，讓內建的 LED 每秒閃爍一次。

void setup() {
  pinMode(13, OUTPUT); // 設定第13接腳為輸出
}

void loop() {
  digitalWrite(13, HIGH); // 輸出D13腳位為高電位(點亮LED)
  delay(1000);            // 等待一秒
  digitalWrite(13, LOW);  // 輸出D13腳位為低電位(熄滅LED)
  delay(1000);            // 等待一秒
}

紅綠燈實作

利用紅、黃、綠三顆 LED，模擬馬路上的紅綠燈切換邏輯。

所需材料： 紅/黃/綠 LED 各一、220Ω 電阻 x3、麵包板。
